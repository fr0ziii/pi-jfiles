# Project File Classification

This context describes how callers ask questions about project files and interpret the resulting answers.

## Language

**Project file**:
A file in the project that a caller may ask about.
_Avoid_: Source file

**Preview**:
A metadata-only view of selected project files, used to review the scope before classification. It does not guarantee that later classification sees the same files or content.

**Classification**:
A model-produced response to a caller's question about a project file. It is evidence to assess, not a verified fact.
_Avoid_: Finding, diagnosis

**Question**:
A caller-defined inquiry about a project file.

**Answer**:
The classifier's response to a question about a project file. An answer may be uncertain and is not proof.
